## 阅读约定

没有 `package` 与 `import` 的 Go 代码块是局部片段，应放入相应函数或包中；注释标明“反例”的内容用于解释错误，不应直接用于业务。带完整 `package main` 的代码块会在 CI 中编译检查。`cmd/`、`internal/`、`examples/` 内是可执行或可测试源码，以这些源码为运行依据。

所有终端命令默认在仓库根目录执行；操作系统专用命令会写明。涉及外部数据库、C 编译器、容器或第三方 RPC 的章节会明确前置条件，不能仅凭纯 Go 单元测试声称这些环境已经验证。

!!! info "版本与覆盖边界"
    语言与标准库基线为 Go 1.26；本机验证版本记录在仓库 `VALIDATION.md`。Go 1.27 新语法独立列在[版本差异](appendix/versions.md)，不要把较早版本限制直接当成最新规范。教程力求覆盖核心知识体系，但标准库全部 API、每个框架和所有运行时实现细节需要继续查阅对应文档。[规范索引](appendix/spec-index.md)与[标准库导航](appendix/stdlib-index.md)提供查漏入口。

## 推荐使用方式

先按学习路线通读，再把每个例子的输入和边界改一遍。每章最后的练习都要求你预测、运行或解释，而不是只抄代码。遇到错误时先保留最小复现，再查当前工具链的 `go doc`。

有 Java、Python、C/C++ 背景的读者应特别关注：Go 按值传参、组合与接口、显式错误返回、goroutine 生命周期、模块版本和 GC 的关系。相同术语在不同语言中不一定具有相同语义。
