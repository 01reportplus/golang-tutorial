# 练习参考答案与验证方向

先独立预测与运行，再看答案。下面给出每章练习的关键结论；开放题并没有唯一架构，完整答案还应包含前提、边界和测试。可执行语义验证见 `examples/basics`，综合项目的实现与测试见对应文章。

## 01—04：入门

**01**：GC 只回收不可达对象。全局 map 持续存入数据且从不删除时，对象仍可达；后台 goroutine 持有输入切片时也可能保留数据。证明泄漏应看引用关系与 heap/goroutine profile，不能只观察一次任务管理器内存。

**02**：GOROOT 是工具链安装根，GOPATH 是模块缓存和工具安装等默认工作区域；GOOS/GOARCH 决定目标，GOMOD 帮助确认模块。普通项目根目录与无嵌套 module 的子目录应找到同一个 go.mod。

**03**：`go run main.go` 只编译指定文件，辅助函数放在 greet.go 时可能 undefined；`go run .` 按包选择文件。命令参数缺失应在入口明确报错并非零退出。

**04**：Printf 格式与参数类型不匹配可能由 vet 或编辑器分析发现，语法和类型检查不一定单独拒绝所有格式问题。定位测试失败应缩小到单个 Test，再检查断言中的 got/want。

## 05—11：声明、类型与函数

**05**：if 初始化声明和内层 `:=` 可能遮蔽外层变量。地址打印只帮助观察本次执行，词法块才是判断依据。外部资源关闭需要显式生命周期协议，不由变量离开作用域自动完成。

**06**：端口解析先 strconv.Atoi，检查 err，再验证 `1 <= n && n <= 65535`。不要先转 uint16 再检查，因为越界信息可能已被截断。定义 Celsius 类型可避免与其他浮点领域量无意混用。

**07**：添加用 `p |= Write`，检查用 `p&Write != 0`，删除用 `p &^= Write`。持久化状态码宜显式固定值，防止 iota 中间插入改变既有协议。

**08**：字符串 range 的索引按字节推进，值为 rune；byte 切片按每个字节，rune 切片按码点索引。`"中文Go"` 有 8 字节、4 个码点；不要将码点数量当成任意文本的字素簇数量。

**09**：defer 后进先出，普通参数立即求值，闭包可能在返回时读取修改后的变量。复制文件先检查打开与 Copy，再处理目标关闭；可以保留主错误并用 errors.Join 聚合关闭错误，成功路径也不能漏掉写入关闭错误。

**10**：自定义 `type NotFoundError struct{ ID int64 }` 并以指针实现 Error，包装后直接 `err.(*NotFoundError)` 不一定成功，`errors.As(err, &target)` 可遍历链。errors.Is 适合检查稳定语义，切勿解析错误文字决定业务。

**11**：复制含 []string 的结构体后，两者仍指向同一元素数组。Clone 需 `clone.Tags = slices.Clone(original.Tags)`；嵌套指针要进一步定义拷贝语义。map 参数重赋值只替换本地 map 值，写 key 修改共享 map。

## 12—17：数据与抽象

**12**：按 rune 截断可先验证 limit 非负，再转换 []rune 并比较长度；空串、边界相等和非法 UTF-8 都要有约定。字素簇处理需要额外 Unicode 分段能力。

**13**：容量足够时 append 可覆盖原数组后续元素，容量不足时会分配独立数组。`s[:0]` 只是长度为零的视图，没有擦除数据，也可能保留大数组。

**14**：有序去重同时使用 seen map 与结果切片，首次出现才 append，见 basics.Unique。组合 key 使用含 TenantID/UserID 的结构体，避免字符串分隔歧义。

**15**：指针接收者可更新库存，值接收者只修改副本。扣减应在同一锁或事务中完成检查和修改，不能只在函数外检查一次。含 Mutex 的结构体使用后不应按值复制。

**16**：只有指针 Write 方法时，`*T` 满足 io.Writer，T 不满足。可寻址局部值调用方法时的自动取地址不改变接口赋值规则。

**17**：Unique 使用 `map[T]struct{}`，约束 comparable；Stack.Pop 将移除位置清零，避免保留指针。迭代器遇到 yield(false) 立即返回，文件资源由覆盖整个迭代生命周期的 defer 清理。

## 18—23：并发

**18**：主函数不等待子 goroutine，返回即进程退出。后台循环需要取消信号与 done/WaitGroup，应用要先通知再等待完成。

**19**：多个生产者都 Done 后，由一个协调者 close(out)。消费者提前退出应取消共享 context，所有阻塞发送都要 select 取消，不让生产者只依赖 out 被接收。

**20**：两个 atomic 分别修改 available/reserved 不能让读取同时得到一致快照，复合不变量用同一临界区或合适事务维护。竞态测试应包含读写路径。

**21**：WithTimeout 后 defer cancel，NewRequestWithContext 把取消传给客户端。超时后远端可能已提交，所以重试写入需要幂等键或查询结果。

**22**：有界缓冲吸收突发，不能长期解决生产率高于消费率；比较性能时同时观察队列等待和内存。减少容量可能提高背压而非降低总吞吐，结论依工作负载。

**23**：Mutex 解锁/加锁、Done/Wait 返回或原子发布提供相应同步依据。无数据竞态仍可能先读后写导致业务丢失更新，把检查与修改放在一个原子业务边界。

## 24—29：标准库

**24**：限制读取 N 字节时，读取 N+1 并检查长度能区别刚好达到与超过限制。Scanner 要检查 Err，Writer 要检查 Flush/Close；不要把空输入与读取失败合并。

**25**：请求体先限流式大小，Decoder 拒绝未知字段，第二次 Decode 必须是 EOF。三态 PATCH 需要额外 presence 标志，`*T` 通常不能同时区别缺失与 null。

**26**：时间排序先比较 Before/After，相等时按 ID 排序；按日历跨天用 AddDate，按耗时用 Duration。测试同步用 channel/锁或 synctest，不用随机延迟制造顺序。

**27**：Client.Timeout 和 ctx 截止共同约束请求，较早到达者先终止。Do 成功后仍检查状态并关闭 body；服务错误、非法输入和下游超时应有不同断言。

**28**：html/template 自动按上下文转义，不能把用户输入转 template.HTML。embed 编译后不依赖原工作目录，但更新需要重新构建；运行时文件方便更新却增加部署路径契约。

**29**：使用唯一约束实现幂等基础；库存可用 `UPDATE ... SET stock=stock-? WHERE ... AND stock>=?` 并检查受影响行数，具体语法依数据库。必须用真实并发事务验证隔离行为，不能只用 mock。

## 30—38：工程与进阶

**30**：go.work 让本地模块优先参与，可能隐藏发布依赖错误，独立验证时关闭工作区。go.sum 校验内容而不是完整锁住构建图。

**31**：API 测试应同时断言状态、响应和副作用，取消测试等待显式 started 信号；扩大并发次数不能代替正确同步。

**32**：基准记录输入、工具链和环境，并用多次采样对比。短切片仍引用大数组时复制所需部分，heap profile 可验证保留变化。

**33**：请求日志加入稳定 request_id、状态与时长；指标避免高基数；资源查询必须同时限制租户和授权范围。

**34**：生成代码是否提交取决于构建和消费者约定，但无论哪种都要固定生成器与输入。构建约束两条路径都需要 CI 检查。

**35**：反射先检查有效性、Kind、指针 Elem 和字段可读性；零拷贝 string 后修改原字节会破坏不可变假设，尤其不能作为稳定 map key。

**36**：C.CString 由 C 堆分配，明确由 C.free 释放；cgo 交叉编译需要目标 C 工具链。RPC 隔离 ABI 与进程失败，却引入网络、协议与部署成本。

**37**：Outbox 投递成功但标记失败时会再次发送，消费者要幂等。幂等键绑定租户、请求摘要和结果；同键不同请求应冲突，不应静默复用。

**38**：存储接口根据调用方所需能力定义，数据库实现替换内存实现后，保留协议测试并增加 SQL 集成测试。关闭顺序为停止入口、等待业务、结束 worker、关闭依赖。

## 39—41：项目验收

**39**：新增统计必须先定义文本语义，再写空输入、Unicode、长行、输出错误与规模边界测试。算法复杂度应包含词频集合，而不是只看逐行读取。

**40**：分页要定义稳定排序和游标一致性；持久化要有迁移、事务与重启测试；认证与租户授权需要独立测试。多实例不能共享进程内自增 ID 与 map。

**41**：按索引归位保证输出顺序；唯一发送者关闭 jobs；遇错 cancel 后 Wait 全部 worker。全部错误汇总与第一个错误取消是不同需求，应使用不同明确契约。
