# 13 · 数组与切片：共享、扩容与拷贝

## 数组长度是类型的一部分

`[3]int` 与 `[4]int` 是不同类型。数组赋值复制所有元素，传参也如此。数组适合固定大小数据，比如哈希摘要和小型矩阵；普通动态序列通常用切片。

```go
a := [3]int{1, 2, 3}
b := a
b[0] = 9 // a[0] 仍是 1
s := a[:2]
s[0] = 7 // a[0] 变成 7
```

切片不是动态数组对象本身，而是对底层数组一段区域的描述。长度是可索引元素数量，容量是从切片起点到可扩展边界的数量，二者分别用 len 与 cap 查询。

## append 必须接收返回值

```go
package main

import "fmt"

func main() {
    base := make([]int, 2, 4)
    base[0], base[1] = 1, 2
    x := base[:1]
    x = append(x, 9)
    fmt.Println(base) // [1 9]，仍共享底层数组
    y := base[:1:1]
    y = append(y, 8)
    fmt.Println(base, y) // [1 9] [1 8]
}
```

容量足够时，append 可能写入原数组；容量不足时，分配新数组并复制元素。扩容倍数是实现细节，不应写依赖“总是翻倍”的逻辑。完整切片表达式 `s[low:high:max]` 能限制容量，从而控制后续 append 的共享范围，但不隔离已有元素的写入。

## 用图理解长度和容量

```text
底层数组: [ 10 | 20 | 30 | 40 | 50 ]
索引:        0    1    2    3    4
s = a[1:3]       └────────┘
s 的元素:         20   30
len(s) = 2
cap(s) = 4       从 a[1] 到数组结尾
```

`s = s[:4]` 可以把长度扩到容量，得到 20、30、40、50；`s[2]` 在扩展之前仍越界，因为索引检查使用长度。容量表示可以重新切片的范围，不表示所有这些元素当前都能直接索引。

函数内 `s = append(s, x)` 只修改该函数的切片值，所以想让调用者获得新长度，应返回新切片。若只传 `[]T` 并希望函数能替换调用者变量，也可以传 `*[]T`，但通常返回值更直观。

## 插入、删除与元素保留

```go
// 删除索引 i，假设 i 已校验。
copy(values[i:], values[i+1:])
var zero T
values[len(values)-1] = zero
values = values[:len(values)-1]
```

清零尾部对包含指针、string、map 等元素尤其重要，否则隐藏在容量区间的引用可能继续保留对象。使用标准库 slices.Delete 时，仍要接收返回的切片，并按所用版本理解尾部清理行为。把旧切片继续交给其他代码使用，会破坏“已经删除”的直觉。

插入中间位置需要移动后续元素，通常 O(N)；大量队头删除应考虑头索引、环形缓冲或其他结构，避免反复搬移。数据结构选型与输入规模有关，不应只为了少写一行代码。

## nil、空切片和 make

nil 切片长度和容量为 0，可以 range、append 与 copy；非 nil 的空切片也长度为 0。很多算法只关心 len，不必区分二者；JSON 等序列化可能区分 null 与空数组，应按 API 契约处理。

`make([]T, n)` 创建长度 n 的切片，元素已经存在且取零值；`make([]T, 0, n)` 创建空切片并预留容量。初学者常先创建长度 n，然后 append n 次，最后得到 2n 个元素。

## copy 与 Clone

`copy(dst, src)` 复制 min(len(dst), len(src)) 个元素，并允许区域重叠。它不会扩展 dst 的长度。`slices.Clone` 可以复制切片元素存储，但指针、map、嵌套切片等元素仍可能共享其内部内容。

删除元素可用 `slices.Delete`。若手动移动指针元素，应清理尾部不再使用的引用，避免底层数组继续保留对象。具体函数是否清理尾部应按目标 Go 版本包文档确认。

## 内存保留与 API 设计

从大文件缓冲区截取很短的切片并长期保存，可能使整个底层数组仍可达。需要独立长期保存时，复制所需部分。将切片返回给调用者前，应明确调用者能否修改、能否在下次调用之后保留。

并发读写同一底层数组需要同步，即使两个切片变量名字不同。一个 goroutine append、另一个读取，看似操作“不同变量”，也可能共享内存或描述信息。

## 二维切片

`[][]T` 是切片的切片，各行可以不同长度，也可能共享底层数组。要创建独立行，逐行 make；要连续存储，可以创建一个大数组后按行切片，明确每行容量以控制 append。

练习：画出两个切片在同一数组上的起点、长度和容量；分别在容量足够与不足时 append，预测原数组变化；解释为什么传入 `s[:0]` 不会清空原数组元素。
