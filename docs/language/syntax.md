# 05 · 语法、声明、作用域与初始化

## 从 token 理解语法

Go 源文件采用 UTF-8。标识符可以包含 Unicode 字母、数字和下划线，但不能以数字开头。团队代码应优先使用清晰、一致、便于搜索的命名。`//` 表示行注释，`/* ... */` 表示块注释，块注释不能嵌套。

Go 会在特定行末自动插入分号，所以左花括号通常必须放在声明或控制语句所在行。`gofmt` 会统一缩进、空白和部分排版；格式正确不等于逻辑正确。

## 四种主要声明

`var` 声明变量，`const` 声明常量，`type` 声明类型，`func` 声明函数。包级声明可以被同包其他文件使用；函数内部还可以使用短变量声明。

```go
package main

import "fmt"

var appName = "tutorial"
const retries = 3
type UserID int64

func main() {
    var count int // 零值为 0
    name := "Go"
    count, enabled := count+1, true // 同一作用域至少一个新变量
    fmt.Println(appName, retries, UserID(7), count, name, enabled)
}
```

`:=` 只能出现在函数内部；左侧至少有一个同作用域的新非空标识符。重复声明与重新赋值不同。`_` 是空白标识符，可以丢弃值，但不能再读取；丢弃错误前必须有明确理由。

## 词法作用域与遮蔽

作用域由代码块决定，包括包、文件、函数、隐式的 if/for/switch 块。内层同名变量会遮蔽外层变量，而不是修改外层变量。

```go
n := 10
if n := 3; n > 0 {
    fmt.Println(n) // 3
}
fmt.Println(n) // 10
```

特别注意在 `if` 内写 `x, err := ...`，可能创建新的 `x`，外层 `x` 没有被赋值。调试时看清变量声明所在块，别只看名字。包名也可能被局部变量遮蔽，例如 `time := ...` 会使后面无法再以 `time.Now()` 引用包。

## 零值与生命周期

未显式初始化的变量具有零值：数值为 0，布尔为 false，字符串为空，指针、切片、map、channel、函数和接口为 nil，数组和结构体递归取字段零值。零值是否可直接操作由类型决定：nil 切片可 append，nil map 不能写入，零值 `sync.Mutex` 可使用。

变量的作用域不等于生命周期。函数返回后，若变量仍被闭包或指针引用，它仍然存活。Go 编译器与 GC 管理其存储，无需人为判断“局部变量一定在栈上”。

## 包初始化

依赖包先初始化，当前包的变量按依赖关系和规定顺序初始化，然后执行 `init` 函数，最后进入 `main`。`init` 没有参数和返回值，不能显式调用。避免依靠跨文件命名顺序组织业务初始化，也避免在 init 中进行不可控网络访问。

需要返回错误、设置超时或注入测试依赖的初始化应写成显式构造函数。`init` 更适合有限的注册工作；隐式副作用越多，排障越困难。

## 练习

预测嵌套三层代码块中同名 `err` 的作用域，再用打印地址验证。为一个结构体列出所有字段零值。思考为什么文件关闭属于生命周期管理，却不是变量词法作用域可以自动保证的事情。
